# Vocabulary learning engine

## Scheduling and migration

FSRS-6 uses the official 21 default parameters, pinned to py-fsrs commit
`9446cb06605c597a063aeee49f7d188d42e34dc2`. Scheduling is deterministic (no interval fuzz), elapsed time is floored to days, and intervals are bounded to 1–36,500 days. Again uses a separate 30-minute app relearning step. These product policies are explicit rather than presented as universal learning constants.

Each `(vocabulary, sense, skill)` has its own stability, difficulty, first/last graded review, practice timestamp, due date and independent-success count. Meaning, word retrieval, English definitions, cloze and lexical usage do not share memory state. The vocabulary due date routes to the earliest active skill; grading one skill cannot postpone another. Extra successful practice keeps an initialized skill's spaced memory unchanged. An uninitialized skill receives a first real assessment even during optional practice.

Room migration 11→12 preserves words, senses, pack memberships, counts, dates, favorite state and tags. Existing heuristic stability is marked `legacy`, not reinterpreted as FSRS. Each skill initializes on its first real grade. No historical reviews are fabricated. A Room migration regression validates schema and preserved data.

Target retention is persisted at 85%, 90% (default) or 95%. Higher targets shorten intervals. The setting is available by tapping the FSRS target in the review header, including an interval preview and explanation. New states use defaults; there is no claim of personally optimized parameters.

## Honest grading and evidence

Hints are optional and explicitly recorded. A successful answer using a hint counts as Hard and does not increase independent successes. A valid alternative is recognized and gets feedback, but leaves target memory, counts and due date ungraded. Learner-declared alternatives also remain ungraded. Incorrect or blank responses allow Again; a successful typed rating requires a checked, accepted answer. Core mastery needs repeated independent meaning and retrieval successes across at least seven days; the visible number is a progress score, not recall probability.

Every submission appends a timestamped immutable event with skill/sense, prompt, expected and actual answer, rating, hint use, category (initial/due/early/alternative/ungraded), pre-answer prediction, elapsed time, retention and scheduler version. Events remain after a word is deleted. Word, state, event, mistake and activity changes share one transaction; a storage failure rolls them all back.

The retention panel evaluates up to the latest 1,000 events. Evaluation uses delayed (≥1 day), due, unhinted typed retrieval/definition/cloze responses; early practice, initial learning, self-rated meaning and alternative answers are excluded. It records empirical recall and Brier prediction error. Fewer than 20 eligible samples shows a history-building message instead of a performance claim. This is an ongoing evaluation pipeline, not evidence of an observed long-term retention gain yet. Mean intervals and rating history also remain available in persisted per-skill records for workload analysis.

## Sense-aware lexical bank

The bank contains 36 reviewed relations / 72 headwords, with separate stable sense identifiers. Each has original English teaching definitions, Persian meaning, contextual examples, a Persian usage distinction, relation type (near synonym/register/collocation/grammar/usage), content version and Cambridge headword reference URLs. Both words must already have a successful learning assessment before a pair enters production Review; incompatible parts of speech are excluded. The revealed comparison shows both English senses and examples, rather than a list of interchangeable translations.

Where a context permits both words (buy/purchase, help/assist, etc.), both are accepted. Grammar and distinctive collocations use a restricted answer set. Other plausible answers can still be left ungraded. This is a curated teaching bank, not an exhaustive synonym dictionary. Its definitions, notes and examples are original wording, not copied dictionary text.
